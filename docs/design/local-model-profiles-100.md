# 수정 100 — 로컬 모델 프로필과 호환 안내

## 사용자 동작

프로필 추가에서 `로컬 모델`을 고르거나, 하위 에이전트 설정의 공급자 등록에서
로컬 연결을 추가한다. 등록한 모델은 주 프로필과 하위 에이전트에 공용으로 사용한다.
정확한 서버 모델 ID와 API 주소는 사용자가 지정한다. 모델 카드의 체크포인트 ID가
서버 별칭과 같다고 가정하지 않는다.

세 가지 프리셋의 공개 사양과 원문은 [사양 자료](local-model-specifications-100.md)에 있다.
Qwen3.8-Flash-Next는 확장 설정을 포함한 1,000,000, DeepSeek-V4.1-Flash와
GLM-5.3-Flash는 1,048,576 토큰으로 설정한다. 서버가 더 작은 길이로 실행되어 있다면
서버를 조정해야 한다. 앱이 하드웨어 권장값으로 조용히 줄이지 않는다.
프리셋 사용 시 프로필별 낮은 컨텍스트 덮어쓰기도 거절한다.

최대 추론은 Qwen의 실제 enum `xhigh`, DeepSeek의 `max`(공식 최대 수치 100),
GLM의 `max`에 대응한다. Qwen에 잘못된 `max` 문자열을 전송하지 않는다.
DeepSeek의 낮은 추론 별칭은 엔진별 매핑 차이가 있어 이번 프리셋에서는 노출하지 않는다.
미확인 최대 출력 길이를 권장 출력 길이로 대체하지 않는다.
자동 압축 기준 기본 90%는 문맥 관리 시점이며 모델의 최대 컨텍스트와 구분한다.

## 전송·인증·실행 위치

기존 `auth_mode=external` 실행 경로와 Responses API를 재사용한다.
프로필에 `external_deployment=local` 표시 정보를 전달하고 카드에 로컬로 구분한다.
공급자 `deployment=local`은 사용자가 관리하는 서버라는 뜻이다. 주소가 같은 PC라는
뜻은 아니며, 별도 Linux 서버도 지정할 수 있다.

- `deployment`: 기존 자료는 `cloud`, 명시적 로컬 연결은 `local`.
- `auth_type`: `api_key` 또는 로컬에 한해 `none`. 키 없는 연결은 DPAPI 읽기와
  Authorization, 생성 설정의 `env_key`를 생략한다. 기존 키 저장 파일은 삭제하지 않는다.
- `credentials_ready`: 인증이 필요한지까지 반영한 UI 준비 상태. `key_saved`와 별개다.
- 로컬만 HTTP 주소를 허용한다. 기존 클라우드 HTTPS 제한은 유지한다.
- `execution_scope`: 로컬 연결은 기본 `local`(Windows 실행만). `all_hosts`를 명시해야
  SSH에서 실행할 설정을 생성한다. 원격의 localhost가 Windows를 뜻한다고 가정하지 않는다.

Chat Completions/Anthropic 형식을 저장하는 기존 기능은 실행 어댑터가 아니다.
현재 런타임은 Responses만 지원하며 Chat Completions 전용 서버는 아직 실행할 수 없다.
서버의 `/v1/responses`, SSE 스트리밍, 도구 호출·결과 후속 요청 지원을 확인해야 한다.
엔진별 `chat_template_kwargs`를 임의로 주입하는 변환기는 이번 변경에 포함하지 않는다.
Responses의 `reasoning.effort`를 실제 추론 템플릿에 전달하는지는 서버 쪽 확인이 필요하다.

모델 연결 시험은 실제 작은 모델 요청 두 번을 전송한다. 작업 파일은 보내지 않고 합성 도구와
임의 검증 문자열만 사용한다. 이 시험은 스트리밍·도구 왕복만 확인한다. 최대 길이의 실제 처리,
추론 강도의 의미, 장기 코딩·취소·재개까지 검증한 것으로 표시하지 않는다.

## 버전 안내

설치된 최신 Codex와 검증된 관리용 앱이 다른 경우의 안내는 모든 프로필의 주황색
경고 대신 `설정 및 관리 → Codex 앱 버전 확인` 아래에 중복 없이 한 번 표시한다.
로그인 실패, 실행 오류, 재시작 필요 경고는 계속 작업 영역에 표시한다.
26.924 설치본의 무결성 검사는 해제하지 않는다. 이번 UI 수정은 최신 앱 호환 패치가 아니다.

## 검증과 남은 연결 작업

Python에서 프리셋 데이터 독립성, 최대 컨텍스트 보존, Qwen effort 대응,
주/하위 역할 생성, 클라우드 동작 유지, 무인증 전송, SSH 범위, 설정 변경 시 재검증을 검사한다.
WPF에서는 로컬/클라우드 목록 구분과 표시, 최대 기본값, 호환 안내의 위치와 실제 오류 보존을 검사한다.
실제 서버 주소·served model ID·엔진/버전·최대 길이·요청 예제가 아직 전달되지 않았다.
실제 모델 연결, 1M 컨텍스트 처리, 사용자 GPU 설정 완료를 주장하지 않는다.
현재 사용자 프로필이나 서비스는 자동으로 재시작하지 않는다.

수정 100 검증 결과(2026-09-29): Python 관련 95개, WPF 29개 검사항목을 통과했다.
기존 네이티브 실행기를 사용하는 별도 모의 서버 시험 2개도 통과했다. 하나는 로컬 주 모델의
도구 왕복·정확한 모델 별칭·무인증·1M 컨텍스트·추론 설정 유지, 다른 하나는 모의 GPT에서
생성된 로컬 역할로 위임하고 부모의 비공개 문맥을 복사하지 않는 동작을 검사한다.
모의 시험 성공은 실제 로컬 모델의 최대 컨텍스트 처리나 엔진 호환성 검증을 대체하지 않는다.
프리셋 제거 및 공유 공급자의 연결 종류 변경 시 전체 레지스트리가 읽히지 않을 수 있는
경계 사례는 저장 전 거절하도록 수정하고 회귀 검사에 포함했다.
다음 실행용 관리 앱은 `20260929-043810-921`이며 묶음 파일 203개의 해시를 확인했다.
네이티브 런타임은 수정 99의 검증된 실행기를 그대로 사용한다.
