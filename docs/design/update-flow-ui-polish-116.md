# 수정 116 — 작업 중에도 공식 앱 업데이트 적용, 26.930.4958 지원, 완전 종료 대기, 관리창 정보 정리

## 1. 작업 중에도 공식 앱 업데이트 등록
- 수정 115는 Codex 창이 하나도 없을 때(완전 종료 시)만 패키지 서비스를 멈추고 등록했다. 프로필이 실행 중이면 «준비된 업데이트 적용»을 눌러도
  매번 "사용 중"으로 보류되어, 사용자에게는 아무 일도 일어나지 않는 것처럼 보였다.
- 관리용 사본은 자기 폴더에서 패키지 신원 없이 실행되고, 관리 런타임(0.153.4)과 26.930 데스크톱은 패키지 서비스
  (`CodexSandboxService.OpenAI.Codex`)를 쓰지 않는다(런타임 코드와 앱 번들에서 서비스 사용처 없음, 빌드 구성 문자열뿐).
- `managed_package_update._quiet`: 실행 중인 Codex 프로세스가 모두 관리용 사본 폴더 안이면 패키지를 붙잡는 것은 서비스뿐이므로
  `-ForceApplicationShutdown`으로 바로 등록한다. 원래 공식 앱 창이 열려 있으면 이전처럼 업데이트 전 검사가 막고, 이미지 경로를 읽지 못한
  프로세스가 있으면 등록을 미룬다.
- 안내 문구: 등록이 미뤄졌을 때 원래 Codex 앱 창을 닫으라는 안내와 완전 종료 시 자동 적용을 알린다. 완료 문구는 "프로필을 다시 열면 새 버전과의
  호환을 확인해 새 버전으로 실행"으로 바꿨다(수정 115부터 새 버전 사본을 만든다).
- 실제 결과: 완전 종료 뒤 자동 적용이 `force_shutdown`으로 실행되어 공식 앱이 26.930.4958.0이 됐고 서비스는 다시 실행 중이다.

## 2. 26.930.4958 지원
- 26.930.3930 이후 소폭 업데이트에서 두 바인딩 이름만 바뀌었다: 작업 맥락 렌더러의 React(`X5`→`Z5`), 추론 검사기(`zve`→`kve`).
- 작업 맥락 렌더러 앵커는 의존성 배열까지 포함해 더 구체적으로 바꿨다(`(g=[o,s,m,t],…,e[15]=g):g=e[15],(0,X5|Z5.useLayoutEffect)(h,g);`).
- 검증: 실제 4958 아카이브에 관리용 사본·원본 동기화 사본 패치를 모두 적용했고 바뀐 6개 파일이 `node --check`를 통과했다.
- 이전 릴리스는 4958 패치에 실패하면 같은 식별값의 26.930.3930 사본으로 계속 실행된다.

## 3. 완전 종료가 "일부 Codex가 종료 요청에 응답하지 않았습니다"로 멈춤
- 26.930은 `app.quit()` 정리(앱 서버 종료 등)에 15초보다 오래 걸린다. 11개 프로필이 동시에 끝나면 더 걸린다. 첫 완전 종료는 15초 뒤 실패했고,
  두 번째 시도 때는 이미 모두 종료되어 있었다.
- `NativeWindowShutdown`: 정상 종료 대기 시간을 60초로 늘렸다(완전 종료 경로 두 곳만 사용).

## 4. 관리창 정보 정리와 사용량 링
- 선택 표시: 강조 고리·아바타·사용량 링이 같은 중심을 쓰고, 강조 고리는 사용량 링 바깥 3px에 그린다. 왼쪽 막대는 고리에 닿지 않고 상태 점은
  아바타 아래로 옮겼다(레일 68px). 125%·150% 배율 렌더링을 시험으로 확인한다.
- 사용량 링: 바깥은 주간, 안쪽은 5시간 남은 양. 하나만 알면 링 하나, 모르면 링 없음. 25% 미만 주황, 10% 미만 빨강, 오래된 값은 흐리게.
- 펼친 카드: 이름·상태, "주간 97% · 5시간 91%"와 얇은 막대(오래된 값은 시계 아이콘), 공급자·모델 칩 하나, 하위 에이전트 칩, 경고 칩 최대 하나.
  초기화 시각·리딤·추론 강도·긴 설명·마지막 확인·SSH 호스트는 레일·카드·상단이 함께 쓰는 도움말 하나에만 보인다.
- 상단: 아바타·큰 이름·상태·공급자/모델 칩, 둘째 줄에 두 링 게이지와 큰 백분율, 경고 칩 하나. 공간이 부족하면 이름을 먼저 줄인다.
- 여는 중·열기 대기·업데이트 중 같은 일시 상태는 상태 표시 문구를 바꾼다(칩 추가 없음).
- SSH 호스트는 카드·상단·작업 바로가기 카드에서 뺐다. 도움말, 연결 상세 아래 줄, 작업 바로가기 검색에는 남는다.
- 검증: 실제 문자열(오래된 Claude 사용량, 인증 실패 설명, max, SSH 호스트 3대)로 배치 시험을 만들고, 긴 설명·"이전 값"·리딤·초기화 시각·max·SSH가
  레일·카드·상단에 나오지 않고 도움말에 한 번 나오는지 확인한다. 링 0·1·2개 경우를 확인한다.
