# 프로필 하위 에이전트 표시와 우클릭 대상

프로필의 주 모델 표기와 별도로 작은 상태 배지를 표시합니다.

| 설정 | 표시 |
|---|---|
| 외부 하위 에이전트 끄기 | 배지 없음 |
| 기본 하위 에이전트와 외부 모델 자동 선택 | 하위 에이전트 · 혼합 |
| 선택한 외부 모델만 허용 | 하위 에이전트 · 외부 전용 |
| 켰지만 외부 모델을 선택하지 않음 | 하위 에이전트 · 모델 미선택 |
| 저장한 설정과 적용된 설정의 revision이 다름 | 배지 끝에 · 대기 |

배지와 상단 설명은 저장된 사용 정책을 보여 줍니다. 현재 실행 중인 에이전트·모델 목록을 뜻하지 않습니다. 툴팁에 선택된 외부 모델 수, 적용 대기 여부와 설정 위치를 안내합니다. 외부 API 주 모델의 자동 선택을 GPT 사용으로 잘못 설명하지 않습니다. 이름·사용량이 그대로인 상태에서 정책만 바뀌어도 배지가 갱신됩니다.

WPF는 ContextMenu를 닫은 뒤 MenuItem.Click을 처리할 수 있습니다. 일시적인 우클릭 대상을 Closed에서 지운 뒤 현재 선택된 프로필로 대체하던 나머지 메뉴도 명시적 ID를 전달하도록 수정했습니다. 이동·로그인·상태 확인·다시 열기·예약·이름 변경·제거·준비 모두 메뉴를 열 때의 대상을 유지합니다. 바로가기 메뉴도 같은 원칙을 적용합니다. 외부 모델 기본 설정 창에 대상 프로필 별칭을 표시합니다.

검증은 실제 WPF 메뉴의 Opened → Closed → Click과 격리된 RPC 기록기를 사용합니다. 창 크기·드래그·입력·설정 팝업에 대한 기존 자체 검사와, 최소 창 크기에서 실제 배지를 렌더링하는 배치 검사도 포함합니다. 사용자 계정을 전환하거나 실제 대화를 중단하지 않습니다.

검증 결과: 관리 모듈 Python 시험 844개 중 843개 통과·1개 건너뜀, ControlCenter 22개와 SSH bootstrap 9개 통과, JavaScript 시험 스크립트 13개 통과, 관리 앱 빌드와 WPF 자체 검사 통과. 배치는 1440×960 및 1024×840에서 확인했습니다. Rust 누적 패치는 새 worktree로 복원한 트리 ID 일치를 확인했으며 Rust 전체 회귀 시험은 이번 변경에서 다시 실행하지 않았습니다.
