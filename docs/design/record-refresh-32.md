# 수정 32 — 열린 대화 갱신과 재부팅 후 실행 연결

후속: 이 문서에서 남겨둔 인라인 한글 조합 문제는 [수정 33](inline-ime-33.md)에서
독립 입력 창으로 변경하고 실제 Codex 창의 조합·프로필 전환 시험으로 검증했다.

2026-09-17. 재부팅 뒤 Open-Synced-Codex로 다시 열자 기록이 보인다는 사용자 보고를 기준으로 확인했다.

## 배포한 변경

- 자동 갱신 어댑터가 `threadRuntimeStatus=active`만 보고 읽기를 보류했다.
  다른 프로세스의 진행 상태를 읽어 온 경우에도 자신의 실행으로 판단해 후속 갱신을 막을 수 있었다.
  해당 창이 보낸 turn/start·turn/steer 요청과 실제로 받는 실행 알림을 별도로 추적한다.
  자기 실행이나 resume 중의 기록 덮어쓰기는 계속 막고, 다른 창의 active 상태는 다시 읽는다.
- 새 기록을 읽는 동안 로컬 작업이 시작된 경우에도 취소 조건을 재검사한다.
- 현재 화면에서 열린 작업을 백그라운드 목록보다 먼저 갱신한다.
- 내용 없는 상태 진단을 `work/control-center/record-signals/status/<PID>.json`에 기록한다.
  읽은 소스 수, 갱신·보류·실패 횟수만 포함하며 대화 본문, 제목, 인증 정보는 쓰지 않는다.
- 재부팅 시 예전 관리용 실행 파일이 프로필 인자 없이 복원되는 경우와,
  업데이트 전 WindowsApps 버전이 아직 실행 중인 경우도 본앱 실행기에서 확인한다.
  기존 UI 저장소의 단일 인스턴스로 조용히 전달하지 않고 정상 종료가 필요한 상태로 알린다.
  실행 중인 본앱을 강제 종료하거나 다른 작업으로 이동시키지 않는다.
- 설치된 26.911.7940.0의 검증된 번들 연결 위치를 추가했다.
  전체 표현식과 일치 개수를 검증하고 모호한 경우 배포를 중단한다.
  설치된 프로그램, 인증 및 대화 저장 형식은 변경하지 않았다.

## 검증

- `artifacts/results/desktop-sync-5e2eb001/report.json`: 실제 설치 버전의 Codex 대화 저장 상태와
  별도 Rust 작성 프로세스를 동시에 실행. SYNC_SECOND와 SYNC_THIRD가 본앱을 다시 열지 않고
  실제 native threadStore에 반영됨. 갱신 두 번, 실패 0. 대화 화면의 픽셀 확인은 아니며
  실제 UI가 사용하는 native 상태를 검사했다. 임시 저장소와 로컬 모형 응답만 사용했다.
- JS 회귀 검사: 외부 active 상태 계속 갱신, 로컬 진행 보호, start 요청과 읽기 경합 보호,
  제목/프로젝트 변경 무효화 신호와 본문 비포함 확인.
- 번들, 실행기, 기록 신호 Python 검사 17개 통과. 새 버전 연결 위치와 중복 표현식 거절,
  이전 설치 버전과 인자 없는 복원 프로세스, 따옴표 포함 UI 경로를 포함한다.
- WPF 자체 검사: 창 연결·복구·분리, 창 버튼, 알림 연결, 메모/체크리스트 통과.

## 아직 해결하지 못한 입력 문제

한글 조합 글자가 구석의 작은 창에 나타나는 문제는 완료로 처리하지 않았다.
외곽 HWND 포커스와 DOM 재연결 조합은 첫 클릭 시험에서 인라인 조합을 통과했지만,
프로필을 여러 번 왕복하면 한영 전환 또는 사이드바 클릭이 실패했다. 이 변경은 배포에서 제외했다.
`NativeWindowHost`의 기존 입력 대상 선택 동작과 `desktop_window_host.cjs`는 수정 31을 유지한다.

시험기는 `--inline-ime`를 추가해 글자 확정 전 `한`과 compositionupdate를 모두 요구한다.
실험용 강제 포커스/DOM 재연결 플래그는 제거했다. input·textarea·contenteditable을 구분한다.
`desktop-input-caf6fddd`에서는 기존 입력 경로에서도 일반 input/textarea의 전환 실패가 나타났고,
contenteditable의 확정 한글 입력은 성공했다. 따라서 모든 입력 조건을 통과했다고 보고하지 않는다.
현재 UI 조합 위치와 프로필 전환 입력 경로는 후속 해결 대상이다.

## 적용

시작 문구는 `대화 자동 갱신·시작 연결 수정 32 · IPC 27`.
진행 중인 작업을 마친 뒤 본앱과 관리창을 정상 종료하고 기존 바로가기로 다시 실행하면
새 어댑터가 적용된다. 기록 갱신을 위해 매번 종료하거나 프로필별 강제 재시작할 필요는 없다.
이미 실행 중인 본앱에 코드를 주입하거나 재시작하지 않았다.
