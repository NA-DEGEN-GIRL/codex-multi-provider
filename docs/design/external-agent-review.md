# 외부 하위 에이전트 검토 평가

DeepSeek 외부 하위 에이전트 세 개에 개인정보, Rust 패치 재현, 설정 메뉴 검토를 나누어 맡겼습니다. 최종 반영 여부는 상위 에이전트가 파일과 격리된 검사로 확인했습니다.

- 개인정보 검토는 개인 실행기·호스트 전용 도우미·문서의 작업 식별자를 찾았습니다. 추가 전체 검색에서 테스트 안의 실제 식별자가 더 발견되어 정리했습니다. 합성 화면의 예시 숫자와 표준 프로토콜 상수는 개인정보로 취급하지 않았습니다.
- Rust 검토는 기존 패치에 이후 수정이 누락된 점과 압축 스키마를 함께 포함해야 한다는 점을 지적했습니다. 누적 패치를 새 기반 인덱스에 적용하고 결과 트리 ID가 동일함을 상위 에이전트가 다시 검증했습니다. 기존 런타임 인덱스는 변경하지 않았습니다.
- 설정 검토는 팝업이 닫힌 뒤 일부 우클릭 동작이 선택 중인 다른 프로필에 적용되는 결함을 찾았습니다. 코드의 대상 해석과 실제 메뉴 Click → RPC 요청을 확인하고 수정했습니다. 설정 대상 별칭이 누락된 안내도 보완했습니다.
- 설정 검토의 첫 호출은 응답 스트림 오류로 실패했고 후속 요청으로 완료됐습니다. 연결이 항상 안정적이었다고 평가하지 않습니다.

이번 범위에서는 근거를 찾고 실제 결함을 지적하는 검토 역할을 수행했습니다. 개인정보 검색에 누락과 과도한 후보가 모두 있었으므로 독립적인 전수 검사를 대신하지 않습니다. 모든 작업 유형에서의 품질이나 장시간 안정성을 보장하는 시험은 아닙니다.
