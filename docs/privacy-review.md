# 커밋 전 개인정보 확인

이 문서는 공개 가능한 소스 트리의 검사 범위를 기록합니다. 실제 계정 정보나 검사 중 발견한 값은 포함하지 않습니다.

- 소스·테스트·문서·Rust 누적 패치와 포함된 스키마를 검사합니다.
- 로그인 파일, API 키, 개인 프로필, 대화 기록, 로그, 빌드 산출물은 Git에서 제외합니다. 로컬의 실제 데이터는 삭제하지 않습니다.
- 개인 계정·작업 식별자, 호스트 별칭, 로컬 작업 경로와 사용자별 시험 이력은 예시로 치환하거나 배포에서 제외합니다. 문서의 치환된 ID는 실제 기록으로 연결되는 주소가 아닙니다.
- 시험에 필요한 계정 허용 목록은 Git에서 제외한 `work/approved-ssh-test-profiles.json`에서 읽습니다. 허용 목록이 없으면 실제 SSH 시험은 거절합니다.
- Gitleaks의 기본 규칙을 사용합니다. `.gitleaks.toml`의 예외는 RFC 6455의 공개 WebSocket nonce 한 값에만 적용합니다.

이 검사는 현재 커밋의 파일 트리를 대상으로 합니다. 이전 커밋에 이미 들어간 개인 경로·시험 식별자는 현재 파일을 고쳐도 과거 Git 이력에 남습니다. 기존 이력을 재작성하거나 원격 저장소에 전송하지 않습니다. 비밀정보 탐지 결과와 개인정보 검토는 별도로 확인해야 하며, 자동 검사가 모든 종류의 개인정보 부재를 증명하는 것은 아닙니다.

검사 도구는 Gitleaks 8.30.0입니다. 전체 후보 파일, Rust 스키마 압축 해제 결과 및 기존 Git 이력 검사에서 비밀정보 탐지가 없었습니다. 이메일·경로·UUID·호스트 이름 후보는 별도로 분류해 합성 시험 값과 표준 상수를 보존했습니다. 개인 데이터가 들어간 실행 로그와 상세 검사 결과는 Git에서 제외한 `work/`에만 남깁니다.
